# SSE & Jobs — Funnel Flow

## Status Saat Ini

Belum ada mekanisme real-time, SSE, websocket, atau background job processor yang terimplementasi di repo ini.

## Belum Ada

- event stream endpoint
- in-memory job registry
- polling coordinator
- queue worker
- retry/dead-letter strategy

## Kapan Dokumen Ini Dipakai

Dokumen ini menjadi relevan saat `funnel-flow` mulai membutuhkan:

- progress import/export,
- live dashboard updates,
- async workflow status,
- background notification atau sync.
